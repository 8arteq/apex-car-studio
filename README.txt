APEX CAR STUDIO - projekt szkolny

Pliki:
- index.html - treść strony
- style.css - wygląd strony
- images - folder na własne zdjęcia (możesz go uzupełnić)

Jak uruchomić:
1. Rozpakuj folder.
2. Otwórz index.html w przeglądarce albo otwórz folder w Visual Studio Code.
3. Jeśli używasz VS Code, możesz zainstalować rozszerzenie Live Server i uruchomić stronę przez "Open with Live Server".

Ważne:
- Zdjęcia w tej wersji są pobierane z Unsplash, więc do ich wyświetlania potrzebny jest internet.
- Formularz używa mailto i może otwierać domyślną aplikację pocztową. Nie jest to formularz z bazą danych.
- Adres e-mail i profil Instagram są przykładowe. Zmień je, jeśli chcesz użyć innych danych.
- Ceny i firma są fikcyjne.
- Przed oddaniem projektu przeczytaj kod i spróbuj samodzielnie zmienić np. tekst, ceny, kolory i zdjęcia.
